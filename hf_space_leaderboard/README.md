# 🏆 LifeBench 2.0 Memory-System Leaderboard

Interactive leaderboard of memory-system accuracy (%) on the [LifeBench 2.0](https://huggingface.co/datasets/C1754955896/Lifebenchv2.0) benchmark, with results across three base LLMs (DeepSeek-V4-Flash, GLM-5.2, Qwen-3.8-MAX) and the LoCoMo benchmark.

- **Paper**: [arXiv:2603.03781](https://arxiv.org/abs/2603.03781)
- **Dataset**: [C1754955896/Lifebenchv2.0](https://huggingface.co/datasets/C1754955896/Lifebenchv2.0)

Click any column header to sort (SH, MH, TR, ND, KU, CR, CD, HI, UA, Micro, Macro, or LoCoMo), or filter by system / base LLM. `Gold Evidence†` is a reference upper bound (reader under perfect retrieval), not a memory system.
