# Source Code

The main source directory contains the `lifebench` package.

## Package Structure

- **[lifebench/](lifebench/)**: Core package.
- `lifebench/event/`: Daily events, phone data, and QA generation.
- `lifebench/persona/`: Persona generation and management.
- `lifebench/utils/`: Shared LLM, I/O, and map utilities.
- `lifebench/memory_file/`: Reserved directory for memory-related files.
