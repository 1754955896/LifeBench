# Event Draft Generation

Generates daily event outlines from broad plans to detailed activities through multiple refinement and optimization stages.

## Core Files

| File | Description |
| --- | --- |
| `graph_generator.py` | Event relationship graph generation. |
| `graph_refiner.py` | Event relationship graph refinement. |
| `timeline_gen.py` | Timeline generation. |
| `event_gen.py` | Event generation. |
| `event_refiner.py` | Event refinement. |
| `event_tree.py` | Event tree structures. |
| `outline_optimizer.py` | Outline optimization. |
| `scheduler.py` | Large-scale schedule planning. |
