# Phone Data Generators

Generates data that simulates phone activity across different application scenarios.

## Generators

| File | Description |
| --- | --- |
| `chat_generator.py` | Chat messages. |
| `communication_generator.py` | Communication records, including calls and SMS. |
| `fitness_health_generator.py` | Fitness and health data. |
| `gallery_generator.py` | Photo gallery data. |
| `note_calendar_generator.py` | Notes and calendar data. |
| `perception_generator.py` | Perception data. |
| `push_generator.py` | Phone push notifications. |
