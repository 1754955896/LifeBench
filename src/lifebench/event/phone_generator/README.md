# phone_generator 子目录 — 手机数据生成器

生成模拟真实手机操作的各类数据，覆盖不同应用场景。

## 生成器

| 文件 | 说明 |
|------|------|
| `chat_generator.py` | 聊天消息生成 |
| `communication_generator.py` | 通讯记录生成（通话、短信等） |
| `fitness_health_generator.py` | 健康与运动数据生成 |
| `gallery_generator.py` | 相册图片数据生成 |
| `note_calendar_generator.py` | 笔记与日历数据生成 |
| `perception_generator.py` | 感知类数据生成 |
| `push_generator.py` | 手机推送通知生成 |
