# Question-Answer Generators

Generates question-answer pairs for evaluating different capabilities of agent memory systems.

## Generators

| File | Description |
| --- | --- |
| `base_generator.py` | Base class for QA generation. |
| `qa_single_generator.py` | Single-hop questions. |
| `qa_multi_hop_generator.py` | Multi-hop reasoning questions. |
| `qa_temporal_generator.py` | Temporal reasoning questions. |
| `qa_knowledge_updating_generator.py` | Knowledge update questions. |
| `qa_conflict_generator.py` | Conflicting-memory questions. |
| `qa_harmful_memory_generator.py` | Harmful-memory questions. |
| `qa_hidden_info_generator.py` | Hidden-information questions. |
| `qa_pattern_recognition_generator.py` | Pattern recognition questions. |
| `qa_unanswerable_generator.py` | Unanswerable questions. |
| `qa_causal_generator.py` | Causal reasoning questions. |
| `phone_operation_generator.py` | Phone-operation question generation. |
